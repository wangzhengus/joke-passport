# 笑场通行证（Joke Passport）

分支：`feature/joke-passport`

约会、酒吧用的可佩戴破冰工具：先亮护照身份卡，再甩冷笑话。

## 第一版功能

- **首页**：头像、姓名、头衔、简介；左侧红条为「笑场通行证」+ 编号
- **笑话页**：内置笑话库；上/下切换；确定返回
- **设置页**：10 个预置头像；进入后开启 SoftAP，手机改姓名/头衔/简介/头像序号
- **编号**：`J` + `YYYYMMDDHHmm` + MAC 末 4 位十六进制；首次启动或擦除 NVS 后重新生成

## 按键

| 页面 | 操作 |
| --- | --- |
| 首页 | 任意键短按 → 笑话；确定长按 → 设置 |
| 笑话 | 上/下换一条；确定 → 回家 |
| 设置 | 上/下选头像；确定保存返回；长按不保存返回 |

## 手机改资料

1. 设备进入设置页（首页长按确定）
2. 手机连接热点 `JokePass-XXXX`（无密码）
3. 浏览器打开 `http://192.168.4.1/`
4. 改姓名/头衔/简介/头像后点保存
5. 设备上确定返回首页（若只改了网页资料，长按返回也可以，网页已写入 NVS）

> 自定义图片上传尚未实现，目前仅预置 10 色头像。
